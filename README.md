#  Portafolio - José Ignacio Ortiz Salazar

Portafolio personal desarrollado como primera entrega del programa en Campuslands. Una *one page* moderna, responsive y optimizada, diseñada para mostrar mis habilidades y proyectos.

##  Demo en vivo
 [Ver portafolio en GitHub Pages](https://joseignacioortizsalazar.github.io/portafolio/)

##  Características
- ✅ **100% Responsive** (se adapta a móvil, tablet y desktop)
- ✅ **Diseño Dark Mode** con contrastes cuidados y profesionales
- ✅ **HTML5 semántico** y accesible
- ✅ **Navegación intuitiva** con menú hamburguesa en móvil
- ✅ **Git Flow** y **Conventional Commits**
- ✅ Desplegado en **GitHub Pages**

##  Tecnologías utilizadas
- HTML5
- CSS3 (Grid, Flexbox, Variables CSS)
- JavaScript Vanilla
- SQL
- Git & GitHub

##  Proyectos destacados
1. **La Pizzería Don Piccolo** - Sistema de gestión de pedidos de pizza con resúmenes de ventas y análisis de ingresos.
2. **Campus Pizza SQL** - Sistema de gestión de base de datos que incluye estructura, datos de prueba y 20 consultas SQL analíticas.
3. **Tienda de Libros** - Diseño de base de datos con normalización hasta 3FN, diagrama conceptual E-R y diagrama UML E-R.
